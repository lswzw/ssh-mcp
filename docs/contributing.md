# 参与贡献

感谢你帮助改进 `ssh-mcp`。项目是一个 Go MCP server，贡献应优先保持用户可见行为、工具 schema 和安全边界的一致性。

## 本地准备

- 使用 Go `1.26.5`，与 `go.mod` 保持一致。
- 在仓库根目录执行 `make build` 验证本机构建。
- 提交前执行 `make check`，它会统一格式化代码、运行静态检查和测试。

## 提交变更

1. 为行为变更补充或更新测试。
2. 保持 MCP 工具名称、字段和状态值的兼容性；如确需变化，请在变更说明中给出迁移方式。
3. 不要在日志、测试夹具或文档中提交真实密码、私钥、主机地址或生产数据。
4. 用户可见的错误和操作说明应清楚区分“未派发”和“已派发但结果未知”。
5. 文档中的命令、默认值和支持范围必须与当前代码一致。

## Pull Request 内容

请说明：

- 变更解决的问题；
- 影响的工具或平台；
- 验证方式和已知限制；
- 是否需要同步更新根目录 README 或 `docs/`。

安全问题请按照仓库根目录 [SECURITY.md](../SECURITY.md) 的方式私下报告，不要在公开 Issue 中发布可直接利用的细节。
