# 目标配置

所有目标和凭据都通过本地 TUI 管理。MCP 客户端只能读取不含凭据的目标清单，不能新增、编辑或删除目标。

## SSH 目标

按 `t` 进入目标列表，按 `n` 新增或选中目标后按 `Enter` 编辑。字段如下：

| 字段 | 说明 |
| --- | --- |
| IP | 远端 IPv4/IPv6 地址；当前不接受主机名。 |
| SSH 端口 | 默认 `22`。 |
| 登录账号 / 密码 | 当前使用账号密码直连；密码留空表示编辑时保留原凭据。 |
| 命令黑名单 | 用英文逗号分隔的 Go RE2 正则；任一匹配就拒绝该目标的 SSH 命令。 |
| 说明 / 环境 | 仅用于本地识别和展示。 |
| 允许文件读写 | `true` 或 `false`；控制专用文件读取和部署工具，新增目标默认为 `true`。 |

保存时会先测试连接。第一次观察到主机指纹，或已保存指纹发生变化时，必须在确认界面核对并按 `y`；拒绝确认则不会保存。指纹异常时目标不会被静默信任。

SSH 远端平台当前必须是 Linux。程序不会自动导入 SecureCRT、Navicat 或其他客户端的配置，也不会读取本机其他程序的凭据。

### 命令黑名单示例

```text
rm /data/.*, cat /etc/passwd, passwd.*
```

这里的 `.*` 是正则表达式。黑名单只能增加限制，不能放宽固定硬拦截；留空表示不增加目标级限制。修改黑名单会使旧的 SSH 工作会话失效。

## 数据库目标

按 `t` 进入目标列表，按 `d` 新增数据库，支持：

- MySQL/MariaDB
- PostgreSQL

| 字段 | 说明 |
| --- | --- |
| IP / 端口 | 以 `IP:端口` 唯一标识实例；MySQL 常用 `3306`，PostgreSQL 常用 `5432`。IPv6 必须使用方括号，例如 `[2001:db8::10]:5432`。 |
| 默认数据库 | `run_sql` 未提供 `database` 时使用。 |
| 只读账号 / 密码 | 查询和列出数据库使用；首次保存必须提供。 |
| 可写账号 / 密码 | 可能写入的 SQL 使用；可选但不填写时禁止写 SQL。 |
| 传输策略 | `tls_verified` 或 `legacy_plaintext`。 |
| CA 证书文件 | 使用 `tls_verified` 时必须填写本机绝对路径。 |
| 说明 / 环境 | 仅用于本地识别和展示。 |

保存前会测试只读连接；配置了可写账号时也会验证可写连接。`tls_verified` 要求证书验证成功，失败不会降级为明文。`legacy_plaintext` 允许旧式明文连接，生产环境建议优先使用经过验证的 TLS。

同一个账号可以同时作为只读和可写账号。若两者相同且可写密码留空，写操作复用只读凭据；若可写账号为空，写操作返回 `write_credential_not_configured`，不会偷偷使用只读身份。

## 启用、停用和删除

在目标列表中：

- `x` 切换启用状态。停用目标再次启用前，必须先按 `Enter` 编辑并完成候选连接验证和保存；不能直接绕过验证启用。
- `Delete` 删除目标，随后按 `y` 确认。
- `r` 刷新列表。

停用或配置变更会撤销旧的执行上下文。每次从停用状态重新启用目标，都必须完成候选连接验证并保存；SSH 目标还须确认主机指纹。

## 本地凭据和主密码

主密码用于解锁本地凭据库。敏感凭据字段以加密封装形式保存，daemon 解锁后才在内存中使用；`state.db` 的普通元数据并不是完整的 SQLCipher 数据库。忘记主密码无法由 MCP 恢复，请妥善保管加密备份。

TUI 还提供：

- 创建加密备份：主页按 `b`。
- 从备份恢复到指定本地文件：主页按 `o`。
- 轮换数据密钥：主页按 `k`，确认文本为 `ROTATE`。
- 修改主密码：主页按 `p`。
- 锁定凭据库：主页按 `l`。

详细维护步骤见 [日常维护](operations.md)。
