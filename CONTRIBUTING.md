## Contributing Guide

Thank you for your interest in contributing to `ssh-mcp`! We welcome bug reports, documentation enhancements, feature proposals, and code contributions.

- **Guidelines & Testing**: Please review the [Contributing Guide](docs/contributing.md) (or [English Documentation](docs/en/README.md)) for instructions on local building, running automated tests, and adhering to architectural safety boundaries.
- **Pull Requests**: Before submitting a PR, ensure that documentation and MCP tool schemas remain strictly synchronized with code changes. Always scrub and remove real credentials, internal IP addresses, or production environment data from test fixtures and logs.

---

## 参与贡献

欢迎为 `ssh-mcp` 提交问题、文档改进和代码贡献。请先阅读 [贡献指南](docs/contributing.md)，了解本地构建、测试和安全边界要求。

提交 Pull Request 前，请确保文档和 MCP 工具 schema 与当前实现一致，并移除测试数据中的真实凭据和生产环境信息。
